# Week 3: Task API with SQLite Database

## Overview
This project upgrades the Task Management FastAPI backend from in-memory storage to a persistent SQLite database.

## Database Information
* **Why SQLite was chosen:** It is lightweight, serverless, zero-configuration, and stores data in a single file, making it ideal for fast local development.
* **Database File Location:** Stored as `tasks.db` inside the `week-03-database/` directory.
